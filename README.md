# Анализ лояльности пользователей Яндекс Афиши

Исследование повторных заказов за июнь–октябрь 2024 года. В анализ вошли 287 786 заказов от 21 854 пользователей. Повторный заказ сделали 61,7% пользователей. При сравнении на одинаковом горизонте в 30 дней направления различий между сегментами менялись.

## Запуск на Windows

1. Откройте PowerShell в папке проекта. Для запуска нужен Python 3.9 и Jupyter. Установите библиотеки в окружение, из которого запускается тетрадь.

   ```powershell
   python -m pip install -r requirements.txt
   Copy-Item .env.example .env
   ```

2. Откройте локальный `.env` и заполните строки значениями из задания. Сохраняйте формат `ИМЯ=значение`.
3. Откройте `afisha_loyalty.ipynb` в Jupyter и запустите все ячейки по порядку. Тетрадь подключается к учебной PostgreSQL и загружает дневные курсы тенге с сервера курса.

В репозиторий входят тетрадь, список зависимостей, `.gitignore` и пустой образец `.env.example`. Заполненный `.env` хранится локально. Исходные выгрузки и примеры строк с идентификаторами пользователей из публичной копии убраны.
